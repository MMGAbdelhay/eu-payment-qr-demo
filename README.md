# eu-payment-qr — Live Demo

Interactive demo for the [eu-payment-qr](https://github.com/MMGAbdelhay/eu-payment-qr) npm package.

Try generating, parsing, and validating EPC QR codes for SEPA payments — directly in the browser.

## Features

- **Generate** — create EPC-compliant strings from payment data + QR preview
- **Parse** — detect and extract payment data from EPC QR strings
- **Validate** — test IBAN, BIC, and full payment validation with real-world examples
